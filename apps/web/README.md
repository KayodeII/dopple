# apps/web — school web app (planned)

One React app for everyone at a school (admins, teachers, students and parents), served on each school's address. Screens depend on the signed-in user's role. There is no separate desktop app (`docs/decisions/0007-web-only.md`).

Start from the "School portal · student home" artboard in the design canvas (link in `docs/context/CONTEXT.md`). Staff screens (classes, enrolments, timetable) build on the API endpoints in the root `README.md`.

Any PR touching this folder needs Before and After screenshots of the running UI on that branch (see `AGENTS.md`). AI-generated images do not count.
