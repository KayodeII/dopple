# apps/desktop — staff desktop app (planned)

One signed app for admins and teachers of every school. On first launch the user enters a school code; the app pins to that school's API. Framework (Electron or Tauri) is an open question in `docs/context/CONTEXT.md`.

Any PR touching this folder needs Before and After screenshots of the running UI on that branch (see `AGENTS.md`). AI-generated images do not count.
